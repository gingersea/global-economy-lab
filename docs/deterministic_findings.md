# 全球经济预判：确定性关系研究报告

> 2026-05-25 | Global Economy Lab

## 摘要

本研究分析了 14 个全球市场（12 个股指 + 黄金 + 原油）自 1985 年以来的确定性关系。核心发现：

1. **均值回归是全球唯一的跨市场确定性格局**：在正常政策环境下，14 个市场全部表现为均值回归（趋势延续系数为负）
2. **EPU 政策不确定性触发系统性系数翻转**：EPU > P75 时，10/13 市场的趋势系数从负翻转为正（均值回归 → 趋势延续）
3. **EPU 高时模型准确率反而更高**（80% vs 74%），关键是用对系数
4. **EPU 不是"噪声"——是系数切换信号**。之前在 EPU 高时压制预测是错的

## 一、数据与方法

- **数据范围**: 1985-2026 (41年)，14 个全球市场
- **核心因子**: trend_momentum（多周期趋势）、mean_reversion（短期反转）
- **EPU 数据**: Baker, Bloom & Davis (2016) 经济政策不确定性指数，1900-2026
- **模型**: 2-factor OLS，EPU P75 分段拟合

## 四、EPU 的正确用法

### 之前的错误
```
EPU > P80 → suppress prediction → 准确率从 60% 降至 45%
原因: 我们用了正常时期的系数去预测高 EPU 时期的收益
```

### 正确的用法
```
EPU 正常: 使用均值回归系数 → 74% 准确率
EPU 高:   使用趋势延续系数 → 80% 准确率（反而更高！）
```

**EPU 不是"噪声"——它是系数切换信号，告诉模型当前市场处于哪个行为模式。**

### 可信度警告

当前 EPU 处于有记录以来最高水平之一（P99）。虽然 EPU 高时的分段模型准确率更高（80%），但当前关税战是全新类型的政策冲击——历史类比有限。判读应视为参考，不作为唯一决策依据。

## 六、方法论贡献

1. **EPU 不应作为二元噪声门控**，应作为连续系数切换信号
2. **均值回归是全球普适规律**，在所有正常政策环境下成立
3. **经济体外部依赖度决定系数翻转剧烈程度**
4. **2-factor 模型（trend_momentum + mean_reversion）已足够**，加入更多因子不提高边际准确率
5. **年频率是最有效的预测周期**：日/月噪声过大（<50%），年预测方向准确率 60-86%
