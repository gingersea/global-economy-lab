# 中国 vs 印度：全球两大新兴市场对比分析

> 2026-05-26 | Global Economy Lab

## 摘要

中国：增长放缓、政策干预扭曲价格信号、模型准确率仅 57%

印度：全球最可预测市场（79%方向准确率）、深度超卖（-1.4σ趋势 + +1.4σ反转=2.8σ极端）、结构性优势独立于全球周期

## 核心数据对比

## 中国

- 官方 GDP 增速 5.0%，但相对历史均值处于-1.3σ——增长放缓正在进行中
- 消费者通胀仅 0.2%，存在通缩压力
- EPU 处于 P97 极端水平，且与美国 EPU 高度同步（r=+0.66）——中美贸易和政策的联动性极强
- A 股（上证综指）处于偏强超买状态：政策"国家队"干预扭曲了价格发现机制
- 模型准确率仅 57%——仅略高于随机，不应用于决策
- **核心问题**：A 股价格不反映市场供需，反映的是政策意图

## 印度

- GDP 增速 6.5%，全球最快的大型经济体
- 失业率 4.2%（-3.2σ），接近理论充分就业水平
- NIFTY 50 处于深度超卖：趋势极弱（-1.4σ）+ 深度超卖（+1.4σ）= 2.8σ 极端，发生概率 < 3%
- 历史上类似条件下次年正收益概率 88%（7/8）
- 纯均值回归市场：反转系数（+2.75）是趋势系数（-0.01）的 271 倍
- **结构性优势**：人口红利（中位年龄 28 岁 vs 中国 39 岁）、数字化（UPI 月交易 > 150 亿次）、全球供应链转移（Apple/三星/Tesla）
- 独立于全球周期——EPU 系数不翻转，内部需求驱动

## 对全球投资者而言

| 中国市场 | 印度市场 |
|---------|---------|
| 政策风险是主要变量 | 均值回归是主要规律 |
| 价格信号失真 | 价格信号清晰 |
| 模型不可靠（57%） | 模型可靠（79%） |
| 离岸市场（恒生）比在岸更反映真实供需 | 内需驱动，独立性强 |
| 短期：政策托底但缺乏方向 | 短期：深度超卖，反转概率高 |
| 长期：面临人口和债务结构性逆风 | 长期：人口和数字化结构性顺风 |
